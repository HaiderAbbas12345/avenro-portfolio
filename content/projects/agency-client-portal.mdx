## Overview

This concept looks at a problem we see from the agency side of development partnerships: client communication scattered across email, shared drives and chat. We designed and built a white-label client portal that an agency could brand as its own and give to every client, to show how we approach work delivered under a partner's name.

## The Challenge

Agencies spend a surprising amount of time on project admin: answering "where are we?" emails, chasing approvals, and re-sending files that got lost in a thread. Clients, meanwhile, often feel they lack visibility into progress.

Off-the-shelf project tools can help, but they are built for the agency's internal team, not for clients. They expose too much, carry another company's branding, and ask clients to learn a complex tool for a few simple tasks. The challenge was a portal that does only what clients need, looks like it belongs to the agency, and is easy to run.

## Approach

We narrowed the client's needs to four tasks: see progress, review and approve work, find files and send a message. Everything in the interface serves one of those four tasks; everything else stays in the agency's internal tools.

Because the portal is white-label, branding was treated as configuration from the start. Logo, colors and domain are set per agency, and nothing in the interface mentions the underlying product. That reflects how we work in partnerships generally: the agency's brand is the one the client sees.

## Solution

The concept includes:

- **A project overview** with a progress bar and milestone list so clients can see where things stand without asking.
- **An approvals queue** where clients review deliverables and approve or request changes, with a clear record of decisions.
- **Shared files** organized by project, replacing attachments buried in email threads.
- **Simple messaging** attached to the project, so conversations stay with the work they relate to.
- **Per-agency theming** for logo, colors and custom domain, plus secure email-based sign-in for clients.

## Technology

Built with Next.js, React and TypeScript, using Auth.js for passwordless client sign-in, PostgreSQL for project data and Tailwind CSS with design tokens that make per-agency theming straightforward.

## Result

This is a concept, so there are no client outcomes or metrics to report. The result is a working prototype that demonstrates how we would build a focused, brandable tool for an agency partner — scoped tightly around what end clients actually need, and designed so the agency, not Avenro, is the brand in front of the client.
